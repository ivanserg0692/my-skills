## Maintenance

- Update this index whenever a local skill is added, renamed, removed, recategorized, or adapted.
- Classify skills by origin: written by the project owner, adapted from an external source, or downloaded and used without substantial adaptation.
- Keep externally sourced skills under `Adapted Skills` even after substantial changes; do not reclassify them as internal.
- Record the original source for adapted and external skills when it is known.
- Keep skill folders as direct children of `.codex/skills/` so Codex discovery keeps working.
- List only local project skills here; do not list system or plugin skills.
